BlackBox: Audio Edition

Getting started & support

A few steps from your first file to your first transformation.

Your first transformation

  1. Add your audio. Drop files or folders into the window, use the + button in Dropped Files, or open them from the File menu. Folders are expanded into the files inside them.
  2. Select a file. Listen to the original and explore the Waveform, Loudness or Music analysis.
  3. Build your pipeline. Click + in Actions and choose an action. For example, add Convert and choose MP3.
  4. Check the preview. Switch the player from Dropped to Preview to hear your changes. While a new preview is being prepared, the player shows “Processing audio…”.
  5. Transform. The Transform button writes new files in the original folders. The adjacent … button lets you choose a different destination and preserve folder structure.

Common questions

Does BlackBox overwrite my originals?

No. Your original files are preserved. If an output name already exists, BlackBox creates a unique filename.

Why does macOS ask for folder access?

BlackBox uses App Sandbox. Opening an individual file does not always allow the app to create a new file beside it. Grant access to the containing folder when prompted, import the folder, or select an output folder with the … button. Your grants are remembered.

Why can Music analysis take a while?

Waveform, loudness and music analysis involve different work. Music analysis can take longer, especially for long recordings. Tempo, key, instrument activity and musical parts are estimates, and the quality of the result depends on the audio.

Can I make several formats at once?

Yes. Add more than one Convert action and choose a different output format for each one. Results show each generated file.

Can I change speed without changing pitch?

Yes. Add Change Speed, choose the speed, and enable Preserve Pitch. Disable it if you want pitch to change along with speed.

Can I automate a saved profile?

Yes, using Shortcuts, AppleScript or the command line. Unattended jobs need previously authorized source and destination folders. Use absolute paths for command-line inputs.

Which Macs and audio files are supported?

BlackBox requires macOS 27 or later and an Apple silicon Mac. Audio format availability depends on macOS codecs. Protected audio cannot be converted.

Need a hand?

Email support@gavz.app with:

  • Your BlackBox version and macOS version.
  • The source format and actions you were using.
  • What you expected and what actually happened.
  • The exact error message, if there is one.

Please don’t attach private or copyrighted recordings unless you want us to review them and have permission to share them. A short, non-sensitive example is usually enough.
